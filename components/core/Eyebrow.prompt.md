One-line: the mono uppercase label that opens every section — use one above every `Headline`.

```jsx
<Eyebrow>Inside the AI you already use</Eyebrow>
<Eyebrow tone="on-navy">Why the answers can be trusted</Eyebrow>
```

Sentence case in the source ("A real example", "One platform, every monitoring problem"), rendered uppercase by CSS. 18px of space below it before the headline.
