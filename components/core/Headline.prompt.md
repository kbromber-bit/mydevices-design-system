One-line: the two-line setup/payoff headline used for the hero and every section heading.

```jsx
<Headline level={1} align="center" setup="Six weeks of work." payoff="Now it just shows up." />
<Headline tone="navy" align="center" setup="AI is only as good as" payoff="the data underneath it." />
```

Rules: ALL CAPS (applied by CSS — write normal sentence case), always a period, never more than ~8 words per line. The payoff line carries the outcome, never a feature.
