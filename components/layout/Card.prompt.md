One-line: the bordered white container behind almost everything — grids, panels, media, quotes.

```jsx
<Card hover rule="var(--md-cat-energy)">…</Card>
<Card radius="md" padding="0">…panel with its own chrome bar…</Card>
```

The 3px `rule` is the only place category colour is allowed. Media cards use `padding="0"` and `overflow:hidden`.
